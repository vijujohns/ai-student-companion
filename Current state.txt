You are continuing the AI Student Tutor project, which is a FastAPI + React application with a RAG-based LLM backend, FAISS vector store, Redis caching, JWT-based authentication, and WebSocket streaming. 

Here is the **current state of the project**:

---

### 1. **Backend**

#### **Directory:** `backend/app/`

##### **a) faiss_store.py**
- Implements FAISS vector store.
- Features:
  - `add_doc(text)`: encode text and add to index.
  - `search(query)`: search for top 3 relevant documents.
  - `load_index()` / `save_index()`: load/save FAISS index from disk.
  - `load_knowledge_base()`: scan KB for updated PDFs and ingest new/modified files only.
  - `load_metadata()` / `save_metadata()` to track last-modified timestamps.
- Status: ✅ Working. Incremental KB update on server start implemented.  

##### **b) rag.py**
- Implements RAG pipeline.
- Features:
  - `generate_answer(query)`: retrieves context using `faiss_store.search` and generates answer via LLM (`llm.generate_response`).
- Status: ✅ Working.

##### **c) cache.py**
- Redis caching.
- Features:
  - `get_cache(key)`, `set_cache(key, value)`.
- Redis host set to actual host IP (localhost change fixed).  
- Status: ✅ Working.

##### **d) api/routes.py**
- `/ask` endpoint (POST) with caching.
- Status: ✅ Working.
- Features added:
  - Redis caching check.
  - Generate answer if cache miss.
- Features parked:
  - Session-based history; currently session_id is unique for each query, so only last query is stored.
  - Will be handled at frontend later.

##### **e) websocket.py**
- WebSocket streaming implemented.
- Endpoints:
  - `/ws`: basic streaming (split answer into words).
  - `/ws/ask`: enhanced streaming with async-to-thread LLM call, word-wise streaming, `[END]` signal.
- Status: ✅ Working.
- Features added:
  - Streaming in near-real-time.
  - Non-blocking LLM execution using `asyncio.to_thread`.
- Features parked:
  - Token/JWT auth for WebSocket (decode_token not implemented yet).
  - Session-based history for multi-turn conversations.

##### **f) auth.py**
- Auth module exists; JWT auth working for REST endpoints.
- Features parked for now:
  - `decode_token` function for WebSocket auth not implemented yet.

##### **g) db.py**
- SQLite DB initialization code exists.
- Status: ❌ `app.db` file not yet created; backend fails if DB file is missing.
- Features pending:
  - Ensure DB file exists on startup or auto-create.
  - Integrate any user/session storage if needed for history/RBAC.

- Features:

  - Displays messages in order.
  - Calls `sendMessage` from `websocket.js` for streaming.
  - VoiceControl and speech utils imported (not modified yet).
- Status: ✅ Working.
- Features added:

##### **b) websocket.js**
- Features:

- Status: ✅ Working.

  - Token/JWT auth header for WebSocket not added yet.
